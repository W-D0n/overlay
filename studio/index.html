                        Réglages

                        OBS

                        Le Studio suit la scène active d’OBS et vérifie la source navigateur. Le mot de passe est celui d’OBS › Outils › Paramètres du serveur WebSocket. Il reste sur cet ordinateur et ne s’affiche jamais une fois enregistré.

                        Twitch

                        Reçoit directement les follows, subs, raids et bits de votre chaîne (EventSub), sans passer par Twitchat. À faire une fois : créez une application sur dev.twitch.tv/console (type « Public »), collez son identifiant client ici, puis connectez-vous : Twitch vous donne un code à taper sur son site. Le Studio ne reçoit jamais votre mot de passe Twitch.

                        Ouvrez la page d’autorisation de Twitch et tapez ce code :

                        Twitchat

                        Twitchat envoie ses alertes (follow, sub, raid, bits) à ce serveur : dans Twitchat, collez l’adresse ci-dessous dans le paramètre WebSocket, puis créez un trigger par alerte avec l’action « WebSocket » et le modèle de message. Elle contient un jeton secret.

                        Alertes reçues

                        Les dernières alertes arrivées au serveur, de toute source : on y voit qu’un trigger fonctionne.
