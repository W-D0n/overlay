Créer un nouvel effet de fond

Pour régler un effet déjà codé, voir tuner-le-fond.html — pas besoin d'écrire de code. Ce guide couvre le cas où l'effet n'existe pas encore.

Le squelette d'un effet

Regarde un effet existant proche de ce que tu veux :

  • Particules/formes qui bougent (canvas + requestAnimationFrame) : RainBackground.js, FirefliesBackground.js, BubbleBackground.js.
  • Motif CSS répétitif animé (sans canvas) : GeometricPatternBackground.js, adapté aux dégradés et motifs géométriques.

Squelette canvas/rAF minimal

// @ts-check
import { resolveColor } from './color-utils.js';

export function MonEffetBackground(options = {}) {
  let intensity = options.intensity ?? 0.5;
  let color = options.color ?? 'var(--color-gold)';

  const canvas = document.createElement('canvas');
  canvas.style.cssText = 'position:absolute;inset:0;width:100%;height:100%;pointer-events:none;';
  const ctx = canvas.getContext('2d');

  let cssW = 0, cssH = 0, rafId = 0;
  let rgb = resolveColor(color); // résolu UNE FOIS, jamais par frame

  function handleResize() {
    const dpr = window.devicePixelRatio || 1;
    const w = canvas.offsetWidth, h = canvas.offsetHeight;
    if (w === 0 || h === 0) return;
    cssW = w; cssH = h;
    canvas.width = w * dpr; canvas.height = h * dpr;
    ctx.scale(dpr, dpr);
    if (rafId !== 0) cancelAnimationFrame(rafId);
    rafId = requestAnimationFrame(tick);
  }

  function tick(timestamp) {
    rafId = requestAnimationFrame(tick);
    ctx.clearRect(0, 0, cssW, cssH);
    // ... dessiner ici, utiliser `rgb` (pas resolveColor(color) à chaque frame) ...
  }

  const observer = new ResizeObserver(handleResize);
  observer.observe(canvas);

  return {
    el: canvas,
    update(newOptions) {
      const o = newOptions ?? {};
      if (typeof o.intensity === 'number') intensity = o.intensity;
      if (typeof o.color === 'string' && o.color !== color) { color = o.color; rgb = resolveColor(color); }
    },
    destroy() {
      cancelAnimationFrame(rafId);
      observer.disconnect();
    },
  };
}

Performance — leçons apprises (contexte stream, CPU partagé avec OBS/jeu/encodage)

  • Ne jamais recréer un objet canvas coûteux (createLinearGradient...) dans tick() — le construire une fois hors boucle, réutiliser via ctx.translate(). Voir ColorDropsBackground.js.
  • Ne jamais recalculer une conversion de couleur coûteuse (HSL↔RGB) par point/par frame si le résultat est déterministe — précalculer une LUT une fois. Voir DotGridAnimated.js (buildHueShiftLUT).
  • Éviter filter: CSS (drop-shadow, blur) sur un élément animé en continu — combiné à un transform 3D, cas connu de saccades dans le rendu offscreen d'OBS (CEF).
  • Résoudre une couleur token une seule fois, jamais par frame — stocker le RGB résolu, recalculer seulement si color change.

Tests

Toute logique pure (calculs, formatage, validation — pas de document/canvas) doit avoir un .test.js à côté, bun test à la racine. La partie DOM/canvas elle-même n'est pas testable dans bun test (pas de DOM dans Bun) — vérifie-la visuellement en navigateur (bun dev/start-dev.js).

Réagir aux alertes — trigger()

Pour qu'un effet réagisse aux alertes stream (follow/sub/raid/bits), implémente trigger(payload) — il reçoit l'événement complet. Référence : DotGridAnimated.js. Les effets qui ne l'implémentent pas sont couverts par l'overlay partagé components/ReactionOverlay.js, rien à câbler.

Réagir au son — setAudioLevel()

Appelée au plus une fois par frame avec { level, bass, mid, treble }, quatre nombres dans [0, 1]. Trois règles :

  1. Ne rien posséder — l'effet reçoit des nombres ; il ne connaît ni AudioContext ni getUserMedia, background-audio.js s'en charge pour toute la page.
  2. Rester correct sans son — si les appels s'arrêtent (micro perdu, preset non réactif), reviens à l'animation normale au lieu de figer sur le dernier pic.
  3. Moduler, ne pas remplacer — à niveau nul, le rendu doit être exactement celui d'un preset non réactif.

Déclare aussi audioReactive et audioIntensity dans le schéma de l'effet : c'est ce réglage, propre à chaque preset, qui autorise l'ouverture du micro. Pour un impact par pic plutôt qu'une modulation continue, réutilise isAudioPeak() de audio-levels.js.
